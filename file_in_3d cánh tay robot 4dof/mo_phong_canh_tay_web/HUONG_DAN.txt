MÔ PHỎNG CÁNH TAY ROBOT 4 TRỤC (BẢN WEB)
=========================================

CÁCH DÙNG
  Bấm đúp file  robot_arm_web.html  để mở bằng Chrome / Edge / Firefox / Safari bản mới.
  Không cần cài đặt, không cần chạy server, không cần mạng (chỉ font chữ Google sẽ
  dùng font hệ thống nếu offline).

GIAO DIỆN
  - Nút ‹ bên trái: thu gọn / mở bảng điều khiển (mặc định: MỞ).
  - Nút › bên phải: mở / đóng bảng số liệu + sơ đồ cơ cấu (mặc định: ĐÓNG).
  - Tab Điều khiển: kéo từng khớp hoặc nhập tọa độ XYZ (động học ngược), tư thế mẫu.
  - Tab Tự động: robot gắp khối từ bệ A sang bệ B và ngược lại.
  - Tab Chi tiết: tô theo khâu, X-quang, tách rời, mặt cắt, tìm và xem tên từng chi tiết
    (bấm để chọn, nhấp đúp để zoom tới).
  - Phím tắt: mũi tên (J1, J2), W/S (J3), [ ] (kẹp), Space (chạy/dừng), H (Home),
    L (nhãn khớp), C (đổi kiểu hiển thị).

LƯU Ý
  - Tên ốc / ổ bi / chốt được SUY RA từ hình dạng và kích thước, không phải tên thật
    trong file CAD (file STL không chứa tên chi tiết).
  - Giới hạn khớp (J2 -10..110 độ, J3 25..160 độ) là giá trị ước chừng, chưa tính va chạm.

THƯ MỤC nguon/ (để chỉnh sửa tiếp)
  template.html      Mã giao diện + mô phỏng (chưa nhúng mô hình)
  robot.bin.gz       Mô hình đã tối ưu (từ robot_arm_full.stl 92 MB, còn ~3 MB)
  assemble.py        Ghép template + mô hình thành robot_arm_web.html
                     (python3 assemble.py inline robot_arm_web.html)
  three.min.js, OrbitControls.js   Thư viện three.js r128
  xu_ly_stl/         Script tách khâu và tối ưu mô hình từ file STL (tham khảo,
                     đường dẫn trong script là của môi trường xử lý)
